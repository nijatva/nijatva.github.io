Camera

Camera2 with manual controls, RAW, night stacking, exposure fusion and panorama.

Medium build Shipped Camera2 · RAW · Night
Open the camera Download the APK The app page

What it does

One job, done properly

  • Manual ISO, shutter and focus
  • RAW capture
  • Night stacking and exposure fusion
  • Panorama
  • A GPS-strip toggle on export

In the browser

What works, and what cannot

The browser build opens your camera through getUserMedia, so it needs no install and no account. It is the same idea, not the same engine: a browser tab cannot reach the sensor directly.

  • Live viewfinder with grid, mirror and front/back switching
  • Photo capture at the stream's own resolution, saved as a JPEG on your device
  • Live readout of what the browser reports: resolution, frame rate, facing mode
  • No manual ISO, no shutter time, no RAW - a browser exposes none of those
  • No night stacking: the browser gives one frame at a time

How it is built

Camera2, and our own maths

  • Camera2 API, no CameraX and no Play Services
  • Manual ISO, shutter and focus behind CONTROL_AE_MODE_OFF
  • RAW capture with a DNG writer, and a 10-bit packed path where the sensor allows it
  • Night and HDR merge run in our own C++: pyramid alignment, inverse-variance merge, demosaic, white balance, tone curve
  • Auto HDR turns a plain photo into a burst when the frame is clipping
  • Grading runs after the shot: looks, per-lens tuning, four sliders, optional portrait blur

Build it

From source

JDK 17, Android SDK 35, NDK 27.2.12479018 and CMake 3.22.1. The native module pins both, so a plain checkout builds without editing anything.

git clone https://github.com/nijatva/nijatva-camera
cd nijatva-camera
./gradlew :app:assembleFullDebug

v0.4.10 debug build, 17 November 2026. Release signing is not set up yet.
