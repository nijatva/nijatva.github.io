Two ways to use it

The same idea in two engines. Pick whichever fits the moment.

Android app (APK)

The whole camera: manual ISO, shutter and focus, RAW and DNG, night and astro stacking, Auto HDR, panorama, five looks, four sliders and per-lens tuning. Works with no network at all.

Download APK →

Web app (browser)

Runs in a tab: live viewfinder, grid, front and back cameras, capture straight to your device. No install, no account. What a browser cannot give it — manual exposure, RAW, stacking — it does not pretend to.

Open the web app →

Everything a camera needs, and nothing it cannot do offline

Each capture is a real file on your phone. Nothing is uploaded, nothing is analysed on a server, and no feature waits for a network.

Pro controls

Manual ISO, shutter time and focus behind CONTROL_AE_MODE_OFF, with a live readout of what the sensor is actually doing: ISO, exposure time, focus state.

RAW and DNG

RAW capture written as a DNG through Camera2's own writer, plus a 10-bit packed path where the sensor allows it — half the file, the same information.

Night and astro stacking

Pyramid alignment and an inverse-variance merge in our own C++, then demosaic, white balance, colour matrix and a tone curve that puts 18% grey where it belongs. Astro takes long exposures on a tripod.

Auto HDR

When the frame is clipping, a plain photo quietly becomes a short burst and is merged, so the sky keeps its colour instead of turning white. It only fires when it can help, and falls back to one frame when it cannot.

Grading after the shot

Five looks, per-lens tuning, four sliders (brightness, contrast, saturation, sharpness), chroma denoise, thresholded sharpening and an optional portrait blur. One pipeline, so a look can never break a capture.

Framing aids

Grid, horizon level with a haptic tick, focus peaking and a histogram — and the photo keeps the exposure and white balance the preview showed you, because the capture locks them instead of converging again.

Part of a suite

Hands a shot to Nijatva Gallery, or to Nijatva Photos for editing, and accepts IMAGE_CAPTURE and VIDEO_CAPTURE so any other app can ask it for a photo. Every hand-off is soft: a missing sibling never crashes it.

Install, or build it yourself

The APK is a debug build while release signing is being set up — it installs fine, and it is the same code that builds here.

Latest release How it talks to the suite

From a plain checkout: JDK 17, Android SDK 35, NDK 27.2.12479018 and CMake 3.22.1. The native module pins both, so nothing has to be edited first.

git clone https://github.com/nijatva/nijatva-camera
cd nijatva-camera
./gradlew :app:assembleFullDebug

Two permissions in total: CAMERA and RECORD_AUDIO for video. No INTERNET, no storage permission, no location.
