What it does

Every feature, no filler

Nothing here needs an account, a subscription or a network connection.

Finding people

  • Photo avatars and coloured initials
  • A to Z sections with instant search
  • Sort by first or last name
  • Favourites tab for starred contacts

Organising

  • Groups with live contact counts
  • Tap a group to filter the list
  • One contact list across SIM, WhatsApp and Google

Backup

  • Export every contact to a .vcf file
  • Import a .vcf file back into the phone
  • Works entirely offline

Optional cloud

  • Zoho sign-in inside the app
  • OAuth with PKCE, no password stored
  • Refresh token so later syncs need no login
Privacy

What it never does

These are structural, not policy promises — you can check each one in the source.

No server-side address bookContacts live in Android's own database on your phone.
No trackingNo ads, no analytics, no third-party libraries.
No forced cloudZoho sync stays off until you sign in; the app is fully usable without it.
No account for the basicsEverything except the optional Zoho import works with no account at all.

The Internet permission exists for one reason only: the optional Zoho import. If you never sign in, the app makes no network calls.
