What it does

Every feature, no filler

Nothing here needs an account, a subscription or a network connection.

Reading

  • Conversation list with names and timestamps
  • Smart categories: All, Personal, OTP, Others
  • OTP detection runs on the device
  • Search names, numbers and message text

Writing

  • Message bubbles with a reply box
  • New message composer
  • Handles sms: and smsto: links from other apps
  • Multipart messages for long texts

As your default SMS app

  • Incoming messages stored in the system database
  • Sent messages recorded on the device
  • All four components Android requires for the role

Look and feel

  • Dark interface built for one-handed use
  • Appearance and Developer screens
  • Soft links to the other Nijatva apps
Privacy

What it never does

These are structural, not policy promises — you can check each one in the source.

No internet permissionThe app cannot upload a message, a number or a contact anywhere.
No cloud backup of SMSMessages stay in Android's own database, exactly where they are now.
No ads, no trackersNo analytics, no crash reporting, no third-party libraries.
No forced default roleYou can read and reply without making it the default SMS app.

Android only lets the default SMS app write to the message database. Set Nijatva Messages as default from the banner inside the app if you want sent messages recorded alongside incoming ones.
