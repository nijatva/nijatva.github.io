Everything you need. Nothing you don't.

Built for speed and clarity — the features that matter, without the bloat.

Powerful browsing

Grid, list, waterfall and compact views. Sort by name, date, size or type, ascending or descending, in a quick bottom sheet.

Real file operations

Copy, move, rename, delete to Trash, batch rename, ZIP and extract — every action on a background thread, with confirmation.

Storage analyser

See what is using space: per-category breakdown, largest files, duplicate detection by content hash and empty folders.

Smart search

Search the current folder or the whole storage, by name or extension, without rescanning everything each time.

Built-in viewers

Images, video and music play in the app. Text and code open in an editor with read-aloud. PDFs render page by page.

Private by design

No internet permission, no analytics, no accounts. Your files never leave the device.
